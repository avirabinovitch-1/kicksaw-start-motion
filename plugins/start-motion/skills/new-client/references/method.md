# New client setup: what it is for

Every stage of the kit starts from the signed SOW and reads what the stage before it made. Setup is the few minutes that make that true for a new client: the SOW is where every stage will look for it, the client has a Drive folder with a Discovery subfolder for the outputs the whole team needs, the person is working in a Claude Project for the client, and the connectors the stages read are connected. Done once, the stage commands then open by saying where the client stands instead of asking where things are.

## Before you say setup is done

- The signed SOW is in the client's Drive folder, the latest signed edition
- The client's Drive folder has a Discovery subfolder (or the Engagement docs subfolder the client already uses)
- Whatever sales shared is listed, with what is missing named as missing, not chased
- The person knows whether they are in the client's Claude Project, and how to make one if not
- The first stage command is named, from what exists

## Calls the skill cannot make for you

- Where Kicksaw's client folders live in Drive
- Whether to work in a Claude Project (strongly recommended) or without one
- Whether to set up the discovery documents now or at the first stage that needs them
